# 로그인 없는 공개 버전

변경일: 2026-10-06. 사용자가 상용화 전 포트폴리오 단계에서는 로그인 없이 사용하도록 요청했다. 이전 PRD의 계정 저장·지정 계정 공유 요구는 이 버전에서 중단한다.

## 현재 사용자 흐름

홈 → 내 CSV/XLSX 업로드 또는 샘플 선택 → 항목 연결·오류·집계 기준 확인 → 추천 대시보드·규칙 보고서 → 편집·계산 검증 → PDF/PPTX/Excel 다운로드.

- 샘플 전용 서비스가 아니다. 기존 파일 업로드, 여러 시트, 오류 처리, 집계, 필터, 차트 편집과 보고 문장 수정 기능을 유지한다.
- 회사 PPTX/Excel 양식을 검사하고 항목 연결을 확인해 현재 보고서에 적용할 수 있다. 양식과 연결은 탭 메모리에만 유지한다. 같은 탭에서 다시 적용할 수 있으나 다음 방문까지 보관하지 않는다.
- 계정 만들기·로그인·저장 작업 목록·템플릿 영구 저장·웹 공유는 제공하지 않는다. 숨겨진 버튼이나 이전 세션으로 서버 API를 호출해도 차단된다.
- 새로고침·탭 종료 시 작업과 양식이 사라진다. 다운로드한 결과 파일은 사용자 기기에 남는다. 브라우저 영구 저장소를 자동 사용하지 않는다. 탭 이탈 경고도 유지한다.
- 기능 제안은 GitHub 공개 이슈 작성 링크로 연결한다. GitHub 계정이 필요한 외부 동선임을 안내한다. HRBIP 서버의 요청함에 저장하거나 접수했다고 표시하지 않는다.

## 데이터 처리

1. CSV/XLSX 읽기·항목 확인·일반 집계·차트와 보고서 편집: 브라우저 메모리.
2. 독립 계산 검증·검증표·PDF/PPTX/Excel 생성: 현재 분석 자료를 서버로 보내 메모리에서 처리하고 결과 반환. 업로드 원본 바이너리는 보내지 않는다.
3. 회사 양식 검사·연결 확인·회사 양식 출력: PPTX/XLSX 양식 파일을 서버 메모리에서 검사·정리·적용한다. 출력 때도 파일과 연결을 다시 검증하며 클라이언트 메타데이터를 신뢰하지 않는다.
4. HRBIP DB·파일 저장소·이전 대용량 전송용 테이블에는 보관하지 않는다. `noStorage`는 DB 접근 시 예외를 내며, 실제 서버 시작 시 SQLite 파일이나 PostgreSQL 풀을 열지 않는다.
5. 회사 양식의 원본은 재검사에 필요한 셀/차트 위치를 유지하기 위해 탭 메모리에 둔다. 서버는 출력할 때마다 정리한 복사본만 사용한다.
6. 호스팅 제공자의 접속/오류 로그와 기반시설 처리는 별도다. ‘개인정보 처리 자체가 없다’, ‘법적 문제가 모두 해소됐다’, ‘기업 자료 보안 검증 완료’로 안내하지 않는다. 시연에는 가상·비식별 자료를 권한다.

## 용량과 실패 처리

- 파일 읽기는 기존 CSV/XLSX 파일당 10MB, 합계 20MB 등의 입력 제한을 유지한다.
- 3MiB 이상 JSON은 브라우저의 `CompressionStream`으로 gzip 압축해 한 요청으로 전송한다. 서버 메모리에서 해제하며 DB 분할 업로드 기능은 차단한다.
- 전송 4MiB, 해제한 JSON 40MiB를 초과하면 오류와 자료 분할/양식 이미지 축소 방법을 알린다. 큰 이미지가 있는 10MB 양식은 읽기 한도 내여도 전송 한도를 넘을 수 있다.
- 오류 발생 시 편집 내용은 그대로 유지한다. 로그인으로 우회하거나 임시 DB에 몰래 저장하지 않는다.

## 실행·기존 데이터

로컬 `npm run dev` / `npm start`와 공개 `PUBLIC_DEMO=true`는 기본적으로 로그인 없는 모드다. 이 모드는 DB 환경설정이 필요 없다. 기존 Vercel DB 비밀값이 남아 있어도 연결하지 않는다.

기존 로컬 SQLite와 Supabase의 계정·저장 작업은 임의로 삭제하지 않았다. 이전 데이터 삭제·보관 방침은 별도 결정 사항이다. 과거 Vercel 배포 URL의 기존 기능도 이 커밋이 소급 변경하지 않는다.

과거 기능의 개발 회귀 검사에 한해 비공개 로컬에서 `HRBIP_ACCOUNTS_ENABLED=true`를 명시하면 기존 코드 경로를 사용할 수 있다. 공개 `PUBLIC_DEMO=true`에서는 이 옵션으로 계정 기능을 켤 수 없다.

## 검증 명령

```powershell
npm test
npx playwright test -c playwright.guest.config.ts
npm run build
npm run check:runtime
```

기존 `npm run test:e2e`는 명시적으로 로컬 계정 모드를 켜는 과거 기능 회귀 검사다. 현재 공개 동선은 `playwright.guest.config.ts`로 검증한다. 실제 실행 결과와 배포 확인은 `WORKLOG.md`에 기록한다.
