# 이후 개선 목록
현재 로컬 1차 도구와 외부 운영 준비를 구분한다.

## 운영·보안
- 외부 배포 대상·공개 범위·비용 선택 후 HTTPS/백업/복원/계정 복구/MFA 또는 SSO.
- 실제 HR 자료 투입 전 보안 검토·암호화·개인정보 보관 정책·소규모 집계 공개 기준.
- 다중 사용자 대규모 운영을 위한 DB/작업 큐/대용량 파싱 worker.
- 계정 탈퇴·운영 관리자 요청함 UI·고정 버전 공유를 수요에 따라 검토.

## 데이터 범용성
- 추가 업무 지원: 공식 법령 API·연혁 적용과 전문가 시나리오 검수, 회사 연차 규칙·출근율/휴직·말일 입사 확장, 계약·공고 의미 비교와 PDF/OCR. 현재 조건·표현 기반 지원 범위를 표시한다.
- 실무 회사 양식 수집 후 호환 범위를 검증하고, PDF도 회사 양식 배치로 변환하는 방식 검토.
- PPT SmartArt/그룹·초과 표의 이어지는 페이지·Excel 수식 재계산/복잡한 인쇄 조판 확장.
- Office와 동일한 양식 렌더링 미리보기, 실제 폰트 가용성 검사, 원자료/고정 이미지에 남은 정보 검사 강화.
- 자유 보고 문장 내 수치와 출처를 구조화해 문장 검증 범위 확대. 현재 임의 해석·서술은 담당자 확인.
- 직원월 스냅샷과 유효기간이 있는 부서·직급 이력 모델.
- 다단 헤더·소계/합계 행·병합 셀의 명시적 변환 도우미.
- 총액과 세부 항목의 의미상 중복 자동 경고 및 기업별 항목 사전.
- 비용 귀속월/지급월을 별도 차원으로 보관하는 모델, 통화 확장.
- 현실적인 파일을 가진 HR 담당자 인터뷰로 필요한 지표·양식 검증.

## 원래 기획의 확장 후보
HR 시스템 직접 연동, 온보딩, 직원 경험/조직문화, 설문, 추가 반복 문서, 보고서 버전 확장,
Tableau, 직원 상세 탐색, 자유 캔버스, 급여 산정. 현재 필수 도구보다 먼저 구현하지 않음.
외부 AI: 집계값 전송 범위·비용·공급자 확인 후 어댑터 연결. 현재는 규칙 기반 표시 유지.
