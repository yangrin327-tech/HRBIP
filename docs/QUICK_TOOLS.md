# 일상 업무 도구

2026-10-07: 대시보드·보고서 자동화는 HRBIP의 대표 기능이다. 보조 도구는 홈 아래 카드 또는 왼쪽 ‘일상 업무 도구’ 메뉴에서 열며, 회사 설정이나 대시보드 업로드 없이 개별적으로 사용한다.

| 도구 | 입력 → 결과 | 직접 링크 |
|---|---|---|
| 날짜·근속기간 계산기 | 두 날짜 → 연·월·일과 총일수, 기준일·이동 일수 → 날짜 | [날짜 계산](https://hrbip.vercel.app/#tools/dates) |
| 두 명단 비교기 | 한 열씩 두 명단 → 공통·각 명단에만 있는 항목·명단 내부 중복·CSV | [명단 비교](https://hrbip.vercel.app/#tools/lists) |
| 인사 문서 작성기 | 성명·회사·재직기간 등 → 재직/경력증명서 미리보기·Word·인쇄 | [문서 작성](https://hrbip.vercel.app/#tools/documents) |

## 날짜 계산

- 1900-01-01부터 2100-12-31까지 지원한다. 잘못된 날짜·역전된 기간은 결과를 만들지 않는다.
- 기본 총일수는 두 날짜의 차이다. 같은 날짜는 0일이며 ‘종료일도 포함’ 선택 시 1일을 더한다.
- 연·월은 시작일의 월별 기념일로 계산하고 해당 일자가 없는 달은 말일을 사용한다. 예: 2024-02-29 → 2025-02-28은 1년 0개월 0일이다. 남은 기간은 일수다.
- 날짜 이동은 기준일을 0일로 하며 정수 -36,500~36,500일을 지원한다. 결과도 지원 날짜 범위 안이어야 한다.
- 달력상 계산으로 휴일·휴직을 제외하지 않는다. 연차·퇴직금 등 법정 산정 기능은 아니다.

## 명단 비교

- 엑셀의 한 열 또는 한 줄에 한 항목인 텍스트를 붙여넣는다. 탭으로 구분된 여러 열은 안내 후 거부한다.
- 빈 줄과 앞뒤 공백은 무시하며 내부 공백과 선행 0은 비교값에 보존한다. 영문 대소문자 구분 여부를 선택한다.
- 중복은 고유 항목 수로 세며, 원본 줄 번호·등장 횟수를 표시한다. 공통 항목의 표기·줄 번호는 A 기준이다.
- 명단당 10,000줄·50만 글자, 화면에는 결과 종류별 처음 200개를 표시한다. 전체 결과는 UTF-8 CSV로 내려받는다.
- CSV의 수식으로 해석될 수 있는 값은 앞에 작은따옴표를 붙인다. CSV에는 셀 형식이 없으므로 Excel로 열 때 사번 등의 선행 0이 자동 변환될 수 있다. 필요한 경우 ‘텍스트/CSV에서 가져오기’로 해당 열을 텍스트로 지정한다.

## 문서 작성

- 재직증명서의 재직기간은 입사일부터 작성일 현재까지다. 경력증명서는 종료일을 직접 입력하며 입사일 ≤ 종료일 ≤ 작성일을 확인한다.
- 부서·직위·담당업무·용도·대표자는 선택 항목이다. 숨겨진 경력 종료일이 재직증명서에 포함되지 않는다.
- Word 다운로드는 편집 가능한 `.docx`다. 내용 복사와 브라우저 인쇄·PDF 저장도 지원한다.
- 작성용 문서로 회사 확인·날인은 별도로 진행한다. 자동 직인이나 발급 사실 확인 기능은 없다.

## 저장과 처리

입력은 도구별 `localStorage`에 자동 저장하고 동일 브라우저·주소에서 복원한다. ‘입력 지우기’는 해당 도구의 입력을 비운다. 다운로드한 파일은 별도다. 다른 기기와 동기화하지 않고 브라우저 데이터 삭제 시 지워진다. 저장 불가 시 화면에 오류를 표시한다.

세 보조 도구의 계산·비교·Word/CSV 생성은 브라우저에서 처리하며 입력을 서버로 전송하지 않는다. 기존 대시보드는 별도의 IndexedDB 저장 및 분석·출력 API를 계속 사용한다. 보조 도구를 열어도 대시보드 작업 내용은 보존한다.

직접 링크는 `#tools/dates`, `#tools/lists`, `#tools/documents`이며 새로고침·브라우저 뒤로 가기를 지원한다.

## 구현과 검증

- `shared/quick-tools.ts`: 순수 날짜 계산·비교·문서 내용 검증.
- `src/QuickTools.tsx`: 폼, 저장, 다운로드, 미리보기. 새 외부 API나 의존 패키지는 추가하지 않았다.
- `tests/quick-tools.test.ts`: 윤년·말일·포함일, 역전 기간, 중복·원본 줄, CSV 수식 보호, 증명서 기간 검증.
- `tests/guest/quick-tools.spec.ts`: 실제 다운로드·XML, 입력 복원·지우기, 대시보드 작업 유지, 접근성·모바일·인쇄.
- Office 데스크톱 앱에서 Word 파일을 직접 열어 편집하는 검수는 별도이며, 자동 검증은 OOXML 구조·한글·특수문자·인쇄 화면을 확인한다.
