# 로그인과 계정 저장 복원 (2026-10-07)

사용자 요청으로 실제 가입·로그인과 계정 작업 저장을 다시 제공한다. 비로그인 샘플·파일 작업과 브라우저 자동 저장은 유지한다. `GUEST_MODE.md`의 전체 계정 차단 설명은 당시 버전 기록이며 이 문서가 현재 기준이다.

## 사용 방법

1. 로그인하지 않고 파일 또는 샘플로 시작한다. 분석 작업·회사 양식은 현재 브라우저에 저장한다.
2. 오른쪽 위 로그인에서 계정을 만들거나 기존 계정으로 로그인한다. 현재 화면의 데이터·필터·문장은 유지된다. 로그인 자체가 분석 작업이나 양식을 자동 업로드하지 않는다.
3. 결과 화면의 **계정에 저장**을 누르면 분석 데이터·연결·기준·필터·대시보드·보고 문장·의견을 온라인에 보관한다. 적용 중인 브라우저 회사 양식도 함께 계정 양식으로 옮긴다. 다른 브라우저 작업이나 전체 양식 목록은 업로드하지 않는다.
4. 다른 기기에서 같은 계정으로 로그인하고 **저장한 작업 → 열기**로 복원한다. **이 브라우저의 작업 가져오기**로 예전 비로그인 작업을 열고 확인한 뒤 계정에 저장할 수 있다.
5. 계정 작업과 템플릿은 명시적으로 저장한다. 편집 후 미저장 상태와 페이지 이탈 경고를 표시한다. 다운로드는 작업을 자동 저장하지 않는다.

## 데이터와 접근 권한

- 공개 웹 계정은 서버 전용 Supabase PostgreSQL `hrbip` 스키마, 로컬 계정은 프로젝트 `.data/hrbip.sqlite`. 서로 다른 저장소이며 브라우저 데이터도 별개다.
- 아이디와 salt를 사용한 scrypt 비밀번호 해시로 인증한다. 원문 비밀번호는 저장·기록하지 않는다. 세션은 HttpOnly/SameSite=Strict 쿠키와 만료 12시간; 공개 사이트 Secure 쿠키·HTTPS·요청 Origin 검사를 유지한다.
- 작업·원본·양식은 소유자별 조회·삭제·내보내기 권한을 서버에서 확인한다. 지정 계정 공유는 조회·필터 탐색으로 한정한다. 미로그인·다른 계정·권한 해제 시 조회와 출력이 차단된다.
- 원본 보관 여부와 분석 데이터 보관은 별개다. 작업 삭제 시 분석 자료·보관 원본·공유 권한을 삭제한다. 회사 양식·템플릿·다운로드 파일은 별도 관리한다.
- 비로그인 결과 내보내기·검증은 일회성 서버 처리다. 계정 사용자가 파일을 다운로드하는 것만으로 현재 작업을 DB에 자동 저장하지 않는다. 계정 양식 등록은 해당 계정에 명시적으로 저장한다.
- 다섯 업무 지원 도구는 로그인 여부와 관계없이 브라우저 처리다. 입력·의견 보관 선택은 브라우저 localStorage이며 계정 동기화 대상이 아니다.
- 실무용 개인정보 처리·보안·법적 적합성 검토, 이메일 인증·비밀번호 찾기, 계정 삭제 기능은 현재 미완료다. 포트폴리오 시연은 가상 자료로 한다. 법적 안전을 보증하지 않는다.

## 실행·배포 설정

`HRBIP_ACCOUNTS_ENABLED=true`일 때 실제 인증·저장을 활성화한다. `PUBLIC_DEMO=true`는 공개 포트폴리오 안내이며 계정을 강제로 끄지 않는다. 계정 기능을 끈 배포에서는 기존 API 전체 차단과 DB 미접속 모드를 그대로 사용할 수 있다.

- 로컬: `.env.local`에 `HRBIP_ACCOUNTS_ENABLED=true`, `APP_ORIGIN=http://127.0.0.1:4173`, `PUBLIC_DEMO=false`, `COOKIE_SECURE=false`. Node 24, `npm ci`, `npm run build`, `npm start`.
- Vercel: 기존 전용 `DATABASE_URL`/`PGPASSWORD`, `PUBLIC_DEMO=true`, `COOKIE_SECURE=true`, `HRBIP_ACCOUNTS_ENABLED=true`, 올바른 Origin/프록시 설정. DB 마이그레이션은 기존 인증용 스키마를 유지하며 공개 테이블로 바꾸지 않는다.
- 비밀값·DB·실제 사용자 자료·테스트 산출물은 커밋하지 않는다. 기존 브라우저 IndexedDB 이름과 버전을 유지해 작업을 보존한다.

## 정상 샘플과 안내

기본 예시는 고의로 넣었던 정산액·연차·공고 문구 차이를 제거했다. 정산 2,130,000원, 연차 비교 57일 대 57일, 대장 잔여 7.5일, 계약·공고 필수 표현의 키워드 점검은 차이 없는 가상 사례다. 법률 내용의 최종 승인이나 실무 완전성을 뜻하지 않는다. 실제 잘못된 입력은 계속 오류·불일치로 표시한다.

대시보드 입력·결과, 회사 양식, 계산 검증, 다섯 지원 도구 각각에 **이렇게 사용하세요** 3단계 안내를 제공한다. 신규 도구는 추가하지 않았다. 정상 샘플은 실제 검증·집계 코드를 거친다.
