홈의 **샘플 목록** 또는 자료 입력 화면의 **다른 샘플 보기**에서 선택한다. 기존 **샘플로 체험하기**는 작은 기본 샘플로 바로 연결된다.

## XLSX 호환성 수정
ExcelJS가 일부 유효한 OOXML을 인식하지 못해 `undefined.sheets` 오류가 발생했다. 브라우저 메모리의 읽기용 복사본에만 다음을 적용한다.

1. SpreadsheetML의 네임스페이스 접두사를 라이브러리 호환 표기로 정규화.
2. 시트의 내부 표 관계에서 절대 경로를 같은 대상의 상대 경로로 정규화.
3. XML BOM 처리, `t="d"` ISO 날짜를 날짜 단위 문자열로 읽기. 2026을 숫자 일련번호로 오해해 1905년으로 바뀌는 문제 방지.

원본 파일과 보관용 원본 바이트는 변경하지 않는다. 원본 XLSX의 6개 시트, 날짜, 해시를 별도로 확인했다. 읽기 실패 시 내부 영어 예외 대신 XLSX 재저장 또는 CSV 업로드 방법을 안내한다.
