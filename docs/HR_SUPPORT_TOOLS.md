# 추가 업무 지원 도구

계약·공고의 수치/조건 대조와 조건별 법령 안내의 최신 로컬 보강 내용은 [검토 개선 기록](SUPPORT_REVIEW.md)을 참고한다.

2026-10-07 사용자 요청으로 기존 날짜·근속기간, 명단 비교, 증명서 작성 도구를 교체했다. 대표 기능은 대시보드·보고서 자동화다. 홈과 왼쪽 메뉴의 개별 버튼으로 다섯 도구를 연다.

| 도구 | 입력 → 결과 | 링크 |
|---|---|---|
| 법령·대응 가이드 | 인사 상황·쟁점·사건일·합의 조건 → 공식 근거·미확인 조건·대응 체크리스트 | [열기](https://hrbip.vercel.app/#tools/law) |
| 퇴사 정산 검토 | 지급·공제 항목과 기재 지급액 → 항목별 합계 대조·차이·추가 확인 자료 | [열기](https://hrbip.vercel.app/#tools/settlement) |
| 연차 기준 비교·검산 | 재직일·확인 조건·회사 규정 또는 대장 → 누적 부여 비교 / 잔여 산식 대조 | [열기](https://hrbip.vercel.app/#tools/leave) |
| 근로계약 확인 | 계약 발췌·TXT/DOCX → 핵심 항목·수당 포함·참조 규정의 원문 위치·확인 목록 | [열기](https://hrbip.vercel.app/#tools/contract) |
| 채용공고 정보 점검 | 공고 내용·TXT/DOCX → 명시된 고용형태·근무지 비교·안내 정보 보완 | [열기](https://hrbip.vercel.app/#tools/recruitment) |

모든 도구에 가상 예시, 직접 입력·점검, 담당자 의견, 결과 복사·TXT·Excel 검토표 다운로드가 있다. 의견 편집은 계산 결과를 지우지 않는다. 입력·조건을 바꾸면 오래된 결과를 비우고 재실행한다.

대조표에 열 이름·단위를 표시한다. Excel의 계산값은 실제 숫자 셀과 원/일 표시 형식으로 저장하고 기준·확인 항목·담당자 의견을 별도 시트로 제공한다.

## 처리·보관·입력

- 입력·계산·문서 추출·출력은 브라우저에서 처리하며 서버·외부 AI에 전송하지 않는다. 공식 링크를 직접 열면 해당 사이트로 이동한다.
- `이 브라우저에 입력·의견 보관`을 선택한 경우에만 도구별 `localStorage`에 저장한다. 같은 주소·브라우저에서 복원되며 기기 간 동기화는 없다. 결과는 복원한 입력으로 다시 계산한다.
- 보관 해제·입력 지우기는 해당 새 저장 키만 삭제한다. 대시보드 IndexedDB와 제거된 도구의 과거 사용자 입력은 함부로 삭제하지 않는다. 저장 실패·손상 구조를 알린다.
- 직접 링크·새로고침·뒤로 가기를 지원하고, 제거된 도구 경로는 홈으로 돌아간다. 대시보드 작업은 별도 보존한다.
- 정산표: CSV/XLSX 10MB, 최대 500항목. UTF-8/EUC-KR, 시트·헤더 행, 항목명·구분·금액·선택 메모 연결과 첫 5행 미리보기. 추천 연결을 확인한 뒤 현재 항목을 교체한다.
- 금액은 원 단위 정수. 구분은 지급/pay 또는 공제/deduction. 빈·중복 헤더, 모호한 구분·누락·음수·소수 금액을 거부하며 행을 조용히 제외하지 않는다. 동일 항목명은 모두 합산하고 경고한다.
- 문서: UTF-8 TXT·DOCX 3MB·20만 글자, DOCX 해제 크기 20MB. 본문 문단만 추출하므로 머리말·꼬리말·도형·이미지는 제외. 내용 확인 후 점검한다. PDF·이미지는 텍스트 붙여넣기. 줄 번호는 입력 텍스트 기준이다.

## 계산·점검 기준

**퇴사 정산**은 모든 지급 − 모든 공제로 재계산하고 입력한 기재액과 대조한다. 기재액 미입력은 미검증, 실제 0과 구분한다. 합계 일치는 개별 산정·공제 타당성·실제 지급 확인이 아니다. 세금·급여·퇴직급여를 새로 산정하지 않는다.

**연차대장**: 발생 + 이월 + 추가 부여 조정 − 사용 − 소멸. 같은 기간·휴가 종류의 일 단위 값, 소수 4자리. 산식 항목은 필수이며 실제 없음은 사용자가 0 입력. 기재 잔여는 선택. 음수 잔여는 확인 항목, 시간→일 자동 환산 없음.

**연차 누적 부여 비교**는 다음 단순 조건을 사용자가 확인한 경우만 계산한다. 일반적인 모든 사례의 법정 연차 계산기가 아니다.

- 상시 5인 이상·주 15시간 이상, 계속근로, 매년 출근율 80% 이상·휴직 없음, 첫해 매월 개근.
- 입사일 1~28일, 재직 40년 이하. 회사는 1월 1일 부여·첫해 개월 비례·월별 개근분 별도. 조건이 다르거나 미확인인 경우 계산 보류, 0으로 대체하지 않음.
- 첫해 개근은 월 기념일마다 최대 11일. 입사 기념일 부여는 15 + floor((경과연수−1)/2), 최대 25일. 마지막 재직일이 기념일 전날이면 그 기념일 부여 제외.
- 회사 첫 1월 1일: 15 × 확인한 비례 개월 ÷ 12. 이후 1월 1일은 당시 만 근속연수의 가산 규칙. 소수 반올림 없음.
- 예시 2024-07-01~2026-09-30, 비례 6개월: 입사일 41일 / 회사 33.5일 / 차이 7.5일. 개별 부여일을 대조표에 표시한다.
- 누적 부여 차이는 현재 잔여·미지급 확정 일수·금액이 아니다. 사용·소멸·기지급 수당과 규정을 별도 확인한다.

계약·공고는 **표현 기반 점검**이다. 표현 발견은 내용 충족, 미발견은 전체 문서 누락을 뜻하지 않는다. 계약직 후 전환 문구를 정규직으로 즉시 분류하지 않는다. 다른 근무지 표기는 같은 주소·복수 배치일 수 있어 확인 항목이다. 공고 안내 보완은 법적 필수 항목이라고 표현하지 않는다. 최종 적법성 판단·지원자 평가는 포함하지 않는다.

- [고용노동부 근로조건 명시](https://1350.moel.go.kr/rtmview.do?id=1000320012): 근로기준법 제17조.
