# 지표 및 데이터 계약 v1
기준은 앱의 확인 단계에서 보여주고 작업과 함께 저장한다. 법률상 산정 기준이 아닌 분석용 정의다.

## 입력 계약
CSV: UTF-8 또는 EUC-KR 선택, 구분자 자동 인식 후 표 미리보기. XLSX: 수식은 저장된 계산 결과만 읽고 재계산하지 않는다. 암호화/매크로/XLS 지원하지 않음.
파일당 10MB, 선택 파일 합계 20MB, 표당 10,000행, 전체 30,000행, 100열. XLSX 압축 해제 크기 제한 검증.
표 역할: 재직 이력(1행=사번+입사일로 구분한 재직 구간), 근태/휴가 기록, 지급 항목 기록.
인사 키는 사번. 동일 사번 재입사는 서로 겹치지 않는 재직 구간으로 허용.
근태/지급은 1행=유일 기록 ID를 가진 개별 기록. ID가 없으면 사번+날짜+항목 조합을 추천하되 사용자가 행 의미 확인. 충돌 시 수정/표 보류.
합계 행이나 교차표는 지원하지 않는다. 헤더 위치 선택과 매핑 제공. 임의 구조 전부를 자동 해석한다는 보장 없음.

## 날짜와 이력
ISO YYYY-MM-DD / YYYY/MM/DD / YYYY.MM.DD 또는 사용자가 지정한 DMY/MDY. 숫자 일련번호는 Excel 날짜 선택 시만.
종료월 포함. 기간은 최대 36개월.
퇴사일 포함 여부는 확인 후 선택. 기본 제안: 마지막 재직일로 포함.
월말 재직: 입사일 <= 말일 AND (퇴사일 없음 OR 퇴사일 >= 말일 [포함 모드], > 말일 [제외 모드]).
같은 사람이 같은 시점에 여러 이력에 걸리면 오류. 재입사는 월말 유일 사번 수로 인원, 입퇴사는 기간 내 유일 사번 수로 표시.
당월 입사: 입사일이 해당월인 사번의 유일 수. 당월 퇴사: 퇴사일이 해당월인 사번의 유일 수.
전월 변화: 기준월 말 인원 - 전월 말 인원. 전월 이력 범위가 완전하다고 확인되어야 함.
입사−퇴사와 변화량을 별도로 산정. 퇴사일 포함, 재입사 등에 의해 다를 수 있음.
사용자가 확인한 완전 이력 시작일/종료일 범위를 벗어난 월의 수치는 null.
현재 명단만 제공했다면 기준일 현재 인원만 계산; 과거/입퇴사 추정 금지.
현재 부서는 현재 분류 기준으로만 표기. 과거 부서별 추세는 부서 이력 없이 생성하지 않는다.
부서/고용형태 필터를 과거에 적용할 때 현재 분류를 기준으로 묶는다는 사실을 명시.

## 지표 사전
|지표|필수 입력|단위/방식|불가 조건|
|---|---|---|---|
|월말 재직|사번, 입사일, 퇴사일, 완전 이력|명, 월말 유일 사번|불완전 이력/날짜 오류/겹친 구간|
|당월 입사·퇴사|위와 동일|명, 해당 월 이벤트의 유일 사번|해당월 전체 이력 미확인|
|전월 대비|월말 두 시점|명, 끝월−직전월|전월말 계산 불가|
|근무시간|사번, 날짜, 항목, 값, 시간 단위|시간 합계|날짜/단위 미확인·문자 혼합|
|휴가 사용|위와 동일, 휴가 항목|일과 시간을 별도로 합산|일↔시간 환산하지 않음|
|제공 지급액|사번, 지급일, 지급 항목, 금액, 통화/단위|원, 정수 합계|통화 혼합·금액 오류|
|월별 지급액|동일|보고 기간의 월별 제공 지급 합계|자료 없는 월은 null|
|지급 항목별 금액|동일|제공 항목별 합계|일부 항목을 총 인건비라 부르지 않음|

근태 항목: 근무 / 연장근무 / 휴가. 일·시간은 변환하지 않고 각각 집계.
금액은 원/천원/만원을 명시 선택하여 원 단위로 변환. 음수 정산 허용. 안전 정수 범위를 넘는 금액은 오류.
월/항목에 행이 없으면 null. '완전한 자료에서 해당 없음'이 확인된 인원 이벤트만 0.
반복 행을 자동 삭제하지 않는다. 원본을 수정하지 않는다. 오류가 있는 영역은 계산 중단; 보류한 영역은 사유 표시.
조인 전에 각 표를 독립 검증/집계. 이벤트→사번 일대일 분류 연결만 하며 인원×근태×급여 행 곱셈 없음.
