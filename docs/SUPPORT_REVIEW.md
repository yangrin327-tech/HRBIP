# 계약·채용공고 점검과 법령 가이드 보강

2026-10-07. 사용자가 계약·공고 결과가 입력을 반복하고 법령 가이드가 키워드에 링크만 연결한다고 지적한 데 따른 **로컬 개선**이다. 공개 배포를 수행하지 않았다.

## 결과에서 달라진 점

점검 결과는 문제 원문과 위치 → 부족하거나 다른 조건 → 확인 이유 → 다음 행동 → 수정·확인 예시를 먼저 보여준다. 예시의 대괄호는 담당자가 실제 조건으로 채울 부분이다. 항목별 공식 근거를 연결하며 TXT·Excel에도 이유·예시를 포함한다.

- 계약: 명시된 월 임금 구성 합계와 총액, 근무 구간과 휴게 분량·위치, 수당 포함 약정의 금액·시간·계산 근거, 참조 규정, 위약금 표현을 점검한다. 복수 시간표처럼 단순 검산하기 어려운 조건은 미확인으로 남긴다.
- 공고: 최초 고용형태와 전환 조건, 계약기간, 임금 금액·기간·충돌, 구체적인 업무·근무지, 실제 지원 경로, 유효한 마감일, 전형·수습 조건을 확인한다. 정보 보완을 법적 의무로 단정하지 않는다.
- 법령 가이드: 퇴직 정산은 날짜 의미·지급 계획·연장 합의, 연차는 상시 인원·주 소정근로시간·기간·출근율, 근로조건은 세부 쟁점에 따라 확인 이유와 처리 순서를 바꾼다. 단순 임금 표현만으로 퇴직 지급기한을 추천하지 않는다.
- 기본 예시는 일반적인 입력으로 유지하고, 별도의 `점검이 필요한 예시` 버튼으로 차이가 있는 계약·공고를 제공한다. 입력 수정 후 재실행하면 발견 내용도 달라진다.

## 구현과 범위

`shared/document-review.ts`는 명시된 수치·조건을 추출하는 규칙 기반 검토다. 외부 AI가 문서 전체를 이해하는 기능은 아니다. 입력 형식·문맥에 따라 발견하지 못하는 사항이 있고, 발췌 밖의 문서·실제 지급·근무·약정 효력은 검증하지 않는다. 발견 0개는 적법성 보증이 아니다.

`shared/law-review.ts`는 지원하는 쟁점의 조건별 안내다. 공식 자료 확인일은 2026-10-07이며, 사건일의 연혁·부칙은 자동 검증하지 않는다. 종료일 +14일은 달력상 비교값이며 법적 만료일을 확정하지 않는다. 제54조 안내는 자료 확인일 기준이며 2026-12-10 시행 예정 변경을 구분한다.

공식 근거: [제17조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029728107), [제36조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029728519), [제20조](https://law.go.kr/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1000113024), [고용노동부 휴게시간·시행일 안내](https://1350.moel.go.kr/rtmview.do?id=1000323934), [연차 안내](https://1350.moel.go.kr/rtmview.do?id=1000012468).
