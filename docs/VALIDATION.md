## 데이터 확인 내용
- 추가 샘플의 전체 24개월 인원·입퇴사·시간·휴가·비용을 원본 XLSX에서 얻은 독립 월별 값과 대조.
- 사용자가 제공한 XLSX의 6개 시트 업로드, ISO 날짜(2017-12-02 / 2024-10-01), 원본 SHA-256 불변 확인.
- 네임스페이스 접두사·BOM·절대 표 경로·ISO 날짜가 포함된 파일의 읽기와 손상 파일 복구 안내를 회귀 검증.
- 샘플은 raw 표에서 계산. 세 표의 행 곱셈 없이 지급 합계 일치.
- 마지막 재직일 포함/제외, 재입사 비중복·겹친 구간, 월말과 당월 이벤트 구분.
- 현재 명단으로 과거 추정하지 않음. 전월 비교 자료가 없을 때 null.
- 기록 ID 중복/다른 시트 중복/없는 인사 사번을 집계 오류로 표시.
- 숫자·날짜 모호성/비정상 날짜·누락/단위 분리·원 환산 정수 확인.
- 금액은 BigInt로 합한 뒤 안전 범위 검증. 큰 양수/음수의 상쇄에도 정수 정밀도 보존.
- 넓은 표에서 고른 수치만 변환. 같은 파일을 중복 가져오면 기록 충돌 검출.
- 미제공 자료는 자료 없음. 시간/일 휴가를 근거 없이 환산하지 않음.
- 필터 변경이 대시보드와 초안 생성에 같은 결과를 사용.
- 저장할 때 미연결 개인정보 열 제거 후에도 기준 키 동일.

## 권한·지속 사용
- 실제 회원가입·로그인, HttpOnly/SameSite 쿠키, 잘못된 비밀번호 차단.
- 소유자 작업 저장/재열기, 담당자 의견 복원, 수정 충돌 검출.
- 템플릿은 design만 포함. 새 작업에 과거 직원 정보가 없음.
- 원본 보관 해제 시 저장 원본 삭제, 작업 삭제 시 관련 자료/권한 삭제.
- 비로그인 401, 비대상 계정 403. 조회·출력·원본·수정·삭제 경로 각각 확인.
- 공유 계정은 서버 집계 필터 탐색 가능; 원시 분석 행/사번 반환 없음.
- 공유 해제 후 다음 조회/내보내기 차단. 브라우저 로그인 흐름도 확인.
- 다른 Origin의 변경 요청 차단. 기능 요청 실제 DB 저장.

## 화면·상태
브라우저로 CSV 오류 발견→작업용 수정→재검증→결과→Excel 다운로드,
XLSX 다중 시트·헤더 선택, 열 형태 지급 자료 연결, 보고서 수동 의견 보호,
차트 클릭에 따른 부서 필터 연결, 차트·테마·틀 편집, 최종 확인→PDF 다운로드를 시험.
저장 500 실패·401 로그인 만료를 모의해 편집 문장이 유지됨을 확인.
업로드/검증 실패·자료 없음·권한 없음 안내 확인. 임의의 네트워크·디스크 고장 전부를 주입한 것은 아님.

## 검수 중 고친 문제
- 세션 테스트에서 로그아웃 쿠키와 새 세션 쿠키를 구분.
- 저장 시 스키마 속성 순서가 바뀌어 기준 키가 달라지던 문제 → 키 정규화.
- select 항목의 접근 가능한 이름을 명시.
- 안내 글자의 낮은 대비 → 색상과 크기 조정.
- 원본 파일과 웹의 서로 다른 헤더/수치 열 → 명시적인 열 펼치기 지원.
- 템플릿 재사용 시 불가능한 차트 종류/누락 자료 안내.
- 일부 차트의 PowerPoint 축 시작을 0 기준으로 맞춤.
- Windows에서 출력 이미지 파일 잠금으로 개발 서버 감시가 종료되던 문제 → 생성 산출물·DB 디렉터리를 Vite 감시 대상에서 제외. 최종 실행은 빌드한 파일을 제공하는 production 모드로 확인.

## 미검증 또는 지원 한계
- 실제 회사 HR 파일과 담당자의 업무 적합성·시간 절감 효과 미검증.
- Windows+설치된 PowerPoint/Excel 검증. macOS, Google Slides, 다른 Office 버전은 미검증.
- 외부 보안 감사·침투·부하·장애 복구·실제 서비스 운영 미검증.
- 임의 기업의 다단 헤더/병합/교차표/직원월 스냅샷 자동 인식은 지원 범위 밖.
- 한국어 장문·매우 많은 범주의 모든 조합을 보장하지 않음. 입력 제한과 페이지 분할 적용.
- 외부 AI 미연결: 규칙 기반 초안은 실제 작동하며 AI 생성으로 표시하지 않음.
- 외부 배포·인터넷 공유 미실행: 사용자 승인한 로컬 실행 범위.

검증 산출물은 artifacts/verification/에 저장하며 Git에 포함하지 않는다.
코드와 테스트를 다시 실행하면 파일 검증을 재현할 수 있다.

## v0.1.2 추가 검증 (2026-10-05)

- 코드 테스트 22개 통과. 통합 자료의 2017년 입사일 유지, 메타데이터 제외, 원본 불변, 중복 키 거부, 인건비 이중 합산 방지, 84개월 중 결측/null과 마지막 확인 인원 150명을 검증했다.
- 브라우저 시나리오 12개 통과. 기존 11개와 통합 Excel 업로드→추천 연결→기간 확인→보고서 의견 보존→네이티브 차트가 있는 PPT 다운로드를 확인했다. UI 문구 변경으로 실패했던 기존 테스트의 대상을 새 문구로 갱신했다.
- 실제 제공 XLSX를 production 서버 4173에서 새 작업으로 업로드했다. 샘플 데이터 호출로 대체하지 않았다. 요청 기간 2020-01~2026-12, 부서/고용형태 전체. 집계 인원은 2026-09 마지막 확인 값 150명이며 2026-12는 계산 불가.
- 기간 제공 합계: 근무 594,145시간, 연장 33,461시간, 휴가 3,461일, 제공 인건비 항목 합계 19,591,449,240원. 각 합계의 자료는 2024-10~2026-09의 24개월이다.
- 원본 SHA256: `34ac6fb02111123adb2ea0fdaa756f4f6bd6a61f1398d379e9fe7cf23b2449ae`. 읽기·출력 전후 동일. 원본 개인정보를 PPT에 포함하지 않는다.
- 데스크톱 및 390px 모바일 화면 확인, 모바일 가로 넘침 없음. 실제 PowerPoint에서 산출물을 열고 모든 슬라이드를 PNG로 렌더링해 점검했다. 네이티브 차트 14개와 편집용 데이터가 포함된다.
- 재현: 서버 실행 후 `node scripts/verify-workbook.mjs "입력 XLSX 절대경로" "출력 PPTX 경로"`. 검증 파일은 artifacts/verification에, 최종 산출물은 outputs에 보관한다. 원본 경로는 코드에 고정하지 않는다.

## 저장 기록·메뉴 수정 검증 (2026-10-05)

- 실제 DB의 기존 작업을 유지하면서 실파일 검증 상태를 별도 작업으로 복원했다. 기간 2020-01~2026-12/전체 필터, 7개 표/20,664행, 보고서 기준 키와 검토 키 일치, 기존 작업 해시 불변을 확인했다. 원본 추가 보관·공유 권한 추가 없음.
- `npm run build` 통과. 데이터 계산 및 서버 코드 변경은 없으며 이번 수정에서는 기존 코드 테스트를 다시 실행하지 않았다.
- 전체 E2E 실행에서 기존 12개 시나리오 통과. 추가한 1개는 실제 화면 제목과 다른 기대 문자열 때문에 실패했다. DOM에서 로그인 후 저장 목록 이동을 확인하고 기대 제목을 수정한 후 해당 시나리오를 재실행해 통과했다.
- 결과의 미저장 안내, 저장 후 복원, 수정 후 저장 필요 표시, 저장 상태 복귀를 실제 브라우저에서 확인했다. 로그인 실패·저장 실패·만료 시 편집 보호 및 공유 권한 회귀 시나리오도 통과했다.
- 추가 시나리오는 상단 로고/계정 외 버튼 없음, 단일 워크스페이스 메뉴, 375px 메뉴 접근, 로그인 후 저장 목록 이동, 가로 넘침 없음을 확인한다.
- 데스크톱/모바일 화면을 시각 확인했고, production 4173 사이트를 새로고침해 새 메뉴가 보임을 확인했다. 사용자 계정의 비밀번호를 입력하거나 세션을 우회하지 않았으므로, 복원된 개인 작업의 사용자 브라우저 열기는 로그인 후 사용자가 확인한다.

## v0.1.3 반복 보고·계산 근거·미리보기 검증 (2026-10-06)

- `npm test`: 27/27 통과. 추가 5개는 이전 행/보고/이력 기간 격리, 새 행·새 범위 유지, 모호한 연결 거부/누락 열 해제, 명시적 단위 재사용, 실제 지표와 근거 일치를 확인한다.
- `npm run test:e2e`: 15/15 통과. 새 시나리오 2개는 실제 로컬 인증→이전 작업 저장→새 CSV(변경 열 이름 포함)→연결 선택/경고→새 기준 확인→새 결과→미리보기 편집→Excel→저장/재열기를 확인하고, 모바일 계산 근거·미리보기의 접근성/가로 넘침을 확인한다.
- 결과: 새 직원 2명만 집계, 이전 직원/의견 미포함, 기존 작업 payload 불변, 별도 작업 저장, 미리보기의 제목·의견과 실제 XLSX 내용 일치. 기존 PDF/PPTX 다운로드, 공유 ACL, 저장 실패·만료 시 편집 보호도 통과했다.
- 안내와 자료 범위 보강 후 해당 코드 5개 및 브라우저 2개를 재실행해 모두 통과했다. `npm run build` 통과. 새 테스트의 ExcelJS 버퍼 타입 충돌은 `xlsx.readFile`로 수정했다.
- 390px 모바일의 새 모달에서 axe WCAG 2 A/AA·2.1 AA 검사 발견 위반 0건. 브라우저 스크린샷으로 반복 설정과 모바일 차트 미리보기를 검토했다. production 4173의 홈/입력 준비 안내도 직접 확인했다.
- 이번 변경에서 출력 엔진은 바꾸지 않았다. 기존 PDF/PPTX의 실제 Office 검증 기록은 위 항목에 있고, 이번 버전의 모든 출력 파일을 Office에서 다시 열어 검수한 것은 아니다.
- 실제 회사 파일 다양성, 단위 의미 자동 판별, 기업 지정 PPT 양식, 시간 절감 효과는 검증되지 않았다. 일반 넓은 표는 수치 열 선택을 다시 거친다. 미리보기는 내용 검토용이며 PDF/PPT의 실제 페이지 배치와 동일한 화면은 아니다.
