## 기술 결정
React + TypeScript + Vite: 상태가 많은 입력/편집 UI와 공통 타입.
Express + Node 24: 한 프로세스에서 API와 웹 제공, 별도 클라우드 불필요.
SQLite (사용자 확인 완료): 로컬 계정·작업·권한을 트랜잭션으로 관리. 내 컴퓨터에서 먼저 완성하는 방식으로 사용자 확인.
ExcelJS/PapaParse: 브라우저에서 XLSX/CSV 읽기. 개인정보는 저장/출력 요청 전 서버로 보내지 않는다.
Recharts: 집계 데이터의 반응형 차트. PPTX는 PptxGenJS 네이티브 차트.
PDF: 서버 Chromium 인쇄, 한글 폰트와 페이지 구조 검증.
규칙 기반 보고서: API·비용 없음. 외부 AI 어댑터는 별도 인터페이스만 제공하며 실제 AI라고 표시하지 않는다.

## 책임 경계
shared: 타입 / 입력 의미 / 검증 / 집계 / 추천 / 보고서 / 템플릿.
src: 화면·메모리 상태·파일 읽기·차트·편집.
server: 인증·권한·저장·내보내기. 공유 계정에 원시 분석 행은 반환하지 않는다.
tests: 데이터 경계·서버 접근 통제·출력 구조·브라우저 흐름.

## 환경
기존 master는 커밋 없는 문서 저장소였다. 원본 문서를 baseline 커밋으로 보존.
작업 브랜치 codex/hrbip-v1. GitHub remote 없음. 로컬 커밋은 Codex 작성자 사용.
배포/공개 저장소/유료 서비스 생성은 이번에 자동 실행하지 않는다.
