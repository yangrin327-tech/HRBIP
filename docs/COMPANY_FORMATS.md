# 회사 양식과 계산 검증 · v0.1.4

요청: PPTX 우선, XLSX도 지원. 자동 연결을 사용자가 확인한 뒤 저장·재사용한다.

- [x] 독립적인 인원/근태/지급액 재집계, 월별·항목별 대조, 자료 부족 상태
- [x] 계산 검증 화면·Excel 검증표·서버 내보내기 차단
- [x] PPTX/XLSX 양식 검사, 위치별 자동 연결 추천·수정
- [x] 원본 배치/서식 유지, 내용 교체, 연결한 과거 값 및 메모 정리
- [x] 계정별 양식 저장·불변 버전·삭제·반복 보고 연결
- [x] 회사 양식 적용 결과와 PPT 넘침/Excel 영역 충돌/지원 제한 안내
- [x] 기능/권한/파일/브라우저 테스트

## 원칙
- 임의 회사 파일을 100% 지원한다고 표시하지 않는다. 지원하지 않는 요소는 등록 전에 설명한다.
- 회사 양식 파일은 명시적으로 등록한 계정의 로컬 DB에 저장한다. 분석 원본 보관 설정과 별개다.
- 연결하지 않은 요소는 기본적으로 비운다. 고정 문구·그림은 사용자가 확인한 것만 보존한다.
- 새 양식 버전을 저장해도 기존 보고 작업은 이전 버전을 참조한다. 삭제된 양식은 기본 양식으로 조용히 대체하지 않는다.
- 검증은 기존 집계 함수 재실행이 아닌 원자료의 별도 재집계와 비교한다. 공통 날짜 해석은 재사용한다.
- 계산 불일치는 출력 차단, 자료 부족/보류는 사유 표시. 원자료 자체의 사실성·사용자 의견까지 자동 보증하지 않는다.
- Excel/PPT는 실제 값과 네이티브 요소를 사용한다. 웹 배치는 반응형을 유지한다.

## 사용 흐름
1. 샘플 또는 내 자료로 결과를 만든다.
2. 결과 상단 **회사 양식 등록·적용**에서 PPTX/XLSX를 업로드한다.
3. 자동 추천과 위치별 내용을 확인한다. 모호한 위치는 비워 둔다. 제목·로고 등 고정 요소는 유지 선택한다.
4. PPT 표는 전체 집계표를 넣거나, 기존 표의 제목 칸을 유지하고 값 칸만 개별 연결한다. 두 방식을 섞지 않는다.
5. 계정에 연결 저장 후 작업에 적용한다. PPT와 Excel을 별도로 선택할 수 있다. 작업 저장으로 선택을 보관한다.
6. **계산 검증·검증표**에서 별도 재집계 결과를 확인하거나 Excel 검증표를 내려받는다.
7. 최종 확인 후 선택한 형식으로 출력한다. 출력 직전 재집계하고, PPT/XLSX를 다시 읽어 단일 지표·차트 캐시를 대조한다.

## 지원 계약과 현재 한계
- 파일 10MB, 압축 해제 전체 60MB/파일별 16MB, PPT 30쪽/Excel 20시트, 연결 위치 700개 이내.
- PPT의 테마·마스터·슬라이드·배경·상자 위치와 기존 텍스트 서식을 보존한다. 기존/텍스트 자리의 차트는 새 네이티브 차트와 편집 데이터로 교체한다. 새 차트의 세부 스타일은 원본과 다를 수 있다.
- PPT 표의 전체 교체는 기존 행·열 수 이내. 개인별 칸 연결은 단일 지표/문구를 지원한다. 글 상자/칸의 예상 넘침은 오류로 안내하며 글씨를 자동 축소하지 않는다.
- Excel은 셀 서식·병합·인쇄 설정을 유지한다. 표 확장은 비어 있고 병합되지 않은 범위에서 가능하다. 기존 네이티브 차트는 위치를 유지하고 새 집계 시트를 참조한다. 기존 수식은 결과값 연결 또는 비우기만 가능하다.
- 셀/차트 단위를 임의 환산하지 않는다. 금액은 원, 인원은 명, 시간/일은 구분한다. 고정 단위 문구는 사용자가 확인한다.
- 매크로, 외부 관계/링크, OLE, ActiveX, 피벗/쿼리, SmartArt·그룹 등은 등록을 거부하고 정리 방법을 안내한다.
- 사진/로고와 마스터·배경의 고정 내용은 사용자가 원본에서 검토해야 한다. 비운 값·노트·댓글·사용하지 않는 차트 데이터/그림은 제거하되, 임의 회사 파일의 모든 숨은 정보 제거를 보장하지 않는다.
- 글꼴 파일은 포함하지 않는다. 사용 환경에 글꼴이 없으면 대체될 수 있다. 웹은 같은 글꼴/강조색과 반응형 배치를 사용한다.
- 웹의 연결 화면은 내용·위치 확인용이다. Office와 동일한 조판 미리보기는 아니다. PDF는 기본 보고서 배치를 사용한다.
- 자유 보고 문장, 원자료의 사실성/항목 의미는 자동 보증하지 않는다. Excel/PPT 구조화 값 대조와 별개로 확인 필요로 표시한다. PDF 출력 후 텍스트 전수 대조는 자동화하지 않았다.
- 검증 결과는 계산 때마다 갱신하며 DB에 과거 통과 도장을 영구 저장하지 않는다. 자료 부족은 0/통과로 바꾸지 않는다.
- 양식 새 버전은 새 ID. 이전 작업은 기존 버전 유지. 저장 작업이 참조하는 양식은 참조 해제·저장 후 삭제한다.

## 구조
`shared/company-format.ts`: 연결 항목·추천·값 계약.
`server/office-xml.ts`: 제한 있는 ZIP/XML 처리와 관계 정리.
`server/company-format.ts`: 검사·정리·회사 양식 출력.
`shared/verification.ts`: 집계 엔진과 별도 계산 경로. 날짜 해석만 공통 규칙.
`server/verify-output.ts`: 생성된 PPT/XLSX 실제 값/차트 캐시 재읽기.
`server/verification-export.ts`: 개인정보 행 없는 검증표.
`src/CompanyFormats.tsx`, `src/CalculationVerification.tsx`: 사용자 흐름.
