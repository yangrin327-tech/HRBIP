# 디자인 및 구조 선택
UI/UX 스킬의 Minimalism/Swiss 권고 중 여백·가독성·그리드·명확한 위계를 채택.
검색에서 나온 파랑 팔레트/마케팅 hero는 사용자 요구와 맞지 않아 적용하지 않음.
화이트 #fff, 배경 #f5f7f3, 초록 #166b4c, 진한 글자 #192c23, 연두 #d9f29d.
홈은 간결한 소개+도구 카드. 별도 마케팅 단계를 추가하지 않고 바로 도구/샘플 진입.
편집은 결과 옆 패널, 모든 순서 변경에 버튼 대안. 44px 조작 영역, 키보드 초점, 색+텍스트 상태.
로컬 시스템 한글 글꼴 사용. 폰트/분석/광고 네트워크 호출 없음.
