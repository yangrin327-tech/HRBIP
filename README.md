# HRBIP

**HR Business Intelligence Partner**

기존 인사 자료를 확인·집계해 종합 인사 보고서와 추천 인터랙티브 대시보드를 만드는 HR 업무 지원 웹을 기획하고 있다.

## 현재 상태

- 기준일: 2026-10-05
- 상태: 질문 1~17 답변 정리 및 PRD v0.3 통합 완료. 웹 구현 전.
- **웹 제작은 사용자가 명시적으로 요청한 뒤 시작한다. 현재 구현하지 않는다.**
- 기간 제한: 없음. 기존 3일 기준은 해제됨.
- 디자인: 흰색·초록·연두, 깔끔하고 신뢰감 있는 업무 화면.
- 편집: BI 비전문가를 위한 추천 틀과 자동 정렬 방식.
- 완료된 산출물: 기획 문서, 질문·답변 정리, 작업 기록, 초기 인포그래픽.
- 아직 없는 것: 웹 소스코드, 실행 중인 앱, AI 연결, 로그인·저장·공유·출력 기능.

## 이어서 작업할 때

새 채팅에서는 이 폴더의 README, 질문·답변 정리, PRD, 제작 흐름, 프로젝트 기록, 작업일지를 먼저 읽도록 요청한다. 새 채팅이 파일을 읽지 않고 이전 대화를 자동으로 기억한다고 가정하지 않는다.

현재 작업은 기획 정리다. 사용자의 새 요청이 웹 구현을 명시한 경우에만 개발을 시작한다. 이후 요구사항 변경은 PRD, 선택 이유는 프로젝트 기록, 실제 작업과 확인 결과는 작업일지에 남긴다.
