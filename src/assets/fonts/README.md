# HRBIP 웹사이트 글꼴

2026-10-07 사용자 요청에 따라 로고를 제외한 웹사이트 전체에 Pretendard를 적용한다. 글자 비율은 유지하고 크기와 굵기로 위계를 구분한다.

- 영문 HRBIP: Archivo, weight 900. Google Fonts 제공 파일. 사용 조건: 같은 폴더의 `Archivo-OFL.txt`.
- 제목·본문·메뉴·버튼·입력창: Pretendard Variable 1.3.9. [공식 소스](https://github.com/orioncactus/pretendard/tree/v1.3.9). 사용 조건: 같은 폴더의 `Pretendard-LICENSE.txt` (SIL Open Font License 1.1).
- Gmarket Sans 파일은 이전 검토본의 자료로만 남아 있으며 현재 화면에는 적용하지 않는다.

폰트 파일을 프로젝트에서 직접 제공하므로 화면을 열 때 외부 폰트 서비스로 접속하지 않는다. 소개 화면의 예시 그래픽은 실제 수치를 나타내지 않는 구성 일러스트다. 샘플 체험은 기존 분석 흐름을 사용한다.
